How the algorithm works and its limits

A DFA is M = (Q, Σ, δ, q₀, F). Start at q₀ and apply δ once for each input symbol. Accept exactly when the final reached state is in F. Empty input ε takes no transition. Every state needs one destination for every alphabet symbol; incomplete definitions are errors, with no implicit trap state. Inputs outside Σ* are invalid, rather than rejected strings. Limits: 1–12 states, 1–94 distinct printable ASCII symbols and 2,000 input characters. This project supports DFA simulation; NFA conversion and minimization are outside its scope.
